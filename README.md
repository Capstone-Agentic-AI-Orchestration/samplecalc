# samplecalc

a basic and simple calculator with working functions

## Getting started

```bash
npm install
npm run dev
```

## Scripts

| Command | Does |
| ------- | ---- |
| `npm run dev` | Run locally in watch mode |
| `npm run build` | Produce a production build |
| `npm test` | Run the test suite |
| `npm run typecheck` | Type-check without emitting |
| `npm run lint` | Lint `src` and `tests` |

## Calculator

Open `/` after starting the server (the default port is 3000). Use the buttons
or number and arithmetic keys. Enter evaluates, Escape/Delete clears, and
Backspace removes a digit. Operations execute from left to right; pressing
an operator again replaces the pending operator. Repeated equals repeats
the last operation. Percent divides the displayed number by 100. AC resets
all state; typing a number also starts over after an error.

`src/calculator.ts` contains the shared calculator engine. The browser script
and page are generated by `src/calculator-page.ts`, so production builds need
no separate asset-copy step. `/health` remains available for health checks.
